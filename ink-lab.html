ink-secondary

Every column is the ink moved toward its own surface until it hits a target contrast ratio — so the rows match across themes and the colour family never changes. The title stays at full ink in every column, so each caption is judged against real content. Roboto Mono's advance is fixed per weight: changing weight never reflows the text, it only changes how much the strokes bleed.

Ratio, not colour: 6.9:1 is what's live in dark today (#B0ADA6). If a ratio reads right at 9:1 in both themes, `ink-secondary` becomes one rule with two values rather than a special case. Weight: the site loads Roboto Mono 400/500 only (layout.tsx), so 300 has to be added if you pick it. At 12px the tag goes spindly at 300 — judge weight on the caption, not the tag.
